Database Sync Instructions

Your site is successfully configured with Supabase DB integrations!

To initialize your database tables and seed the starting products and settings, please follow these steps:

  1. Open your Supabase Dashboard: Supabase Dashboard.
  2. Navigate to your project "fckwikbneaphuftbwfbl".
  3. Go to the SQL Editor tab in the sidebar.
  4. Click "New query".
  5. Open the file db_schema.sql created in your project workspace folder, copy its contents, paste them into the SQL Editor, and click Run.
  6. That's it! Once run, all dynamic pages, products, settings, and image paths are connected to your Supabase tables.
Note on Fallback: If the tables are not created yet, the admin panel and public pages automatically fallback to loading from the local configuration so that your website never crashes.
